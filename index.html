02How TabGuard is different

We built TabGuard around one principle: your data belongs to you, and you should always know its state.

  • ✓
    Verified saves
    Every save gets a SHA-256 checksum. On restore, the checksum is recomputed and compared — if the data changed, restore is blocked with a clear message instead of opening wrong tabs.
  • ✓
    Restore preview
    See exactly how many tabs and the first URLs before you click restore.
  • ✓
    Export to JSON
    One-click JSON export at any time. No login required. Your data is portable by design.
  • ✓
    Auto-backup every 30 minutes
    Chrome saves a snapshot every 30 minutes while open, so you can recover after a crash or restart.

04Questions

When will TabGuard launch?

Submitted to the Chrome Web Store on 21 October 2026. Review usually takes 2–7 days. Survey participants and waitlist members are notified first.

What happens to my data if I stop using it?

You own your data. Export to JSON at any time. No lock-in, no deletion traps.

Why should I trust you with my tabs?

We don't sync your tabs to any server. All tab data stays local on your device. All core features work offline, locally.

Will it stay free?

Yes for all current features. If a Pro tier is added later, existing users keep everything they have today, free.

What does "verified saves" actually mean?

When you save, TabGuard computes a SHA-256 checksum of every tab URL in the session and stores it. When you restore, it recomputes the checksum and compares. If the stored data has been altered or corrupted, restore is blocked with a clear warning instead of opening the wrong tabs. The checksum is stored locally, in IndexedDB, and never leaves your device.

Does TabGuard sync my tabs across devices?

No. Every session is stored only in your browser's local IndexedDB. There is no server, no account, and no network request. To move data, export to JSON and import on another device.

Which browsers are supported?

TabGuard targets Chromium-based browsers. The current listing is published for Chrome only. Brave, Edge and Vivaldi should work when installed manually, but they are not officially tested yet.

Is it really free? Will it stay free?

Yes. All features are free today, no account required. If a Pro tier is added later, every feature you have today will remain free for you. There is no license key and no device lock.

What happens to my saved sessions if I uninstall?

Chrome deletes extension storage when you uninstall. Export your sessions to JSON first (one click per session) so you keep a portable copy. This is why export is available on every session.
